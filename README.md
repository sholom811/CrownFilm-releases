# Crown Film

Installers for Crown Film. **Download the latest from [Releases](https://github.com/sholom811/CrownFilm-releases/releases/latest).**

- **Mac** (Apple Silicon, macOS 12+): open the `.dmg`, drag Crown Film to Applications.
- **Windows** 10/11: run `CrownFilm-Setup-x.y.z.exe`. If SmartScreen appears: More info → Run anyway.

You need a Crown Film license key and an internet connection.
